# n8n en Render

Proyecto listo para desplegar n8n en Render usando Docker.

## Deploy

1. Subir este proyecto a GitHub.
2. Entrar a Render.
3. Crear un nuevo Blueprint.
4. Conectar el repositorio.
5. Deploy automático.

## Variables importantes

Configurar manualmente:

- WEBHOOK_URL
- N8N_BASIC_AUTH_USER
- N8N_BASIC_AUTH_PASSWORD

Ejemplo:

WEBHOOK_URL=https://tu-app.onrender.com

## Login

Al abrir la app:

usuario: el configurado
contraseña: la configurada
